# 🧱 Brick Breaker

Brick Breaker is a modern recreation of the classic arcade game **Arkanoid**, built entirely with **vanilla JavaScript**, HTML, and CSS — no external libraries or frameworks.

The goal is simple: control the paddle, bounce the ball, and break all the bricks without letting the ball fall. Easy to start, challenging to master.

---

## 🎮 Gameplay

- Control the paddle to keep the ball in play
- Break all bricks to complete the level
- Avoid letting the ball fall below the paddle
- Score points by destroying bricks

---

##  Features

- Classic arcade-style gameplay
- Smooth paddle and ball mechanics
- Collision detection system
- Score tracking
- Responsive controls
- Lightweight and fast (no frameworks)

---

##  Built With

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6+)**
